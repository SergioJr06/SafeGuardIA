1. Preparação (Obrigatório)

Antes de qualquer coisa, você precisa ativar o "músculo" do projeto (o ambiente virtual).

    Abra o terminal na pasta do projeto e digite:
    .\venv\Scripts\activate (No Windows).

2. Configuração do Ambiente (O Painel)

Para definir quais EPIs serão cobrados em cada câmera:

    No terminal, rode: streamlit run src/app.py
    E abra o ngrok: ./ngrok http (porta:x)

    No navegador, selecione a câmera e marque os EPIs obrigatórios para aquele setor.

    Clique em Salvar.

3. Preparação de Dados (IA)

Para preparar as fotos do celular para o treinamento da IA:

    Coloque as fotos brutas em: dataset/raw

    No terminal, rode: python src/utils.py

    As fotos prontas (quadradas e leves) aparecerão em: dataset/processed

    Suba a pasta processed para o Roboflow para treinar a inteligência.

4. Teste de Monitoramento (A Câmera)

Para ver a inteligência em ação (ou testar a conexão):

    No terminal, rode: python src/TesteCamera.py

    Uma janela abrirá mostrando o vídeo em tempo real. Pressione 'Q' para sair.
